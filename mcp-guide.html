外部连接 / MCP 直连

把自己的服务接进小手机

网页直接向你填写的 MCP 地址发送请求。无需经过半糖内置网易云云服务，也不会自动切换到其他服务器。

一、准备服务地址

向服务提供者获取一个可用的远程 MCP 地址，例如 https://你的域名/mcp。它必须提供 MCP 协议接口，普通网页、网易云歌单分享链接、GitHub 仓库链接都不能代替它。

支持 Streamable HTTP（2025-11-25 等初始化握手协议）及旧版 HTTP + SSE。不支持网页里直接运行 command / args 本地命令；仅支持无需授权或 Bearer Token 授权，暂不支持 OAuth 登录流程。

没有服务地址时，需要先由服务提供者开通，或将 MCP 项目部署为远程服务。切换界面本身不会生成网易云账号接口，也不会解决服务所在网络不可达的问题。

二、在网页中连接

  1. 进入「外部连接 → MCP 直连」。网易云扫码登录使用独立的「网易云」TAB，无需填写 MCP 配置。
  2. 填写服务地址，选择服务提供者说明的连接协议：通常 /mcp 选 Streamable HTTP，/sse 选旧版 SSE。
  3. 如果提供者要求 Bearer Token，将令牌填入专用密码框；没有要求则留空。
  4. 点击「连接并发现工具」。出现「已连接，N 个工具」表示握手与工具发现完成；零个工具表示该服务未提供可调用工具。

也可以展开「已有 MCP 配置？粘贴导入」，粘贴单个服务的 mcpServers JSON 或 URL，再点击连接。

连接信息和令牌只在本次页面中使用；刷新后需重新填写并连接。令牌不写进角色聊天或备份。工具参数中的内容会发送给你连接的服务。

三、让 char 自动读取

  1. 连接成功后选择服务提供的工具，填写参数并执行一次，确认返回的是歌曲、歌词或正文。
  2. 导入歌单时，服务需返回 tracks 数组，每首含 name、src（可播放的音频直链），以及可选的 artist、lyrics。
  3. 在「自动读取给 char」选择歌曲或小说类型，把只读查询工具设为自动读取源。
  4. 切换到「一起听读」，选择 char 并开启主动聊天。页面打开期间每 30 秒查询一次；离开连接 TAB 可以继续，刷新或关闭页面后需重新绑定。

只绑定查询当前歌曲、歌词、阅读正文的工具。播放、发送、删除等会修改数据的工具不适合定时调用。可用功能和账号登录方式由所连接的服务决定。

四、连接不上时

服务端需要允许网页跨域访问。服务管理员应核对实际网页 Origin（包括 http / https 的区别），允许合法来源，而不是关闭来源校验。

允许来源示例：http://mymellow.top
允许方法：POST, GET, OPTIONS
允许请求头：Content-Type, Authorization,
  MCP-Protocol-Version, Mcp-Session-Id
暴露响应头：Mcp-Session-Id
OPTIONS 预检必须返回成功的跨域响应

401 / 403：检查授权和来源许可。404：检查服务路径及协议。网络错误：检查服务是否在线、网络是否可达、HTTPS 证书是否有效和 CORS 配置；浏览器有时无法区分这些原因。

正式远程服务应使用 HTTPS。本机调试可以使用 localhost / 127.0.0.1，但手机里的这些地址指手机本身，不能用来访问另一台电脑，且浏览器可能另有本地网络权限要求。

MCP 是连接协议，无法保证网易云登录、会员歌曲或特定小说网站访问；这些能力需要服务本身提供，并遵守对应平台权限。
