这次更新了什么

  • 统一过滤模型的思维链输出，覆盖短信、通话、线下、番外、旧世与剧情总结。
  • 兼容思考标签、嵌套和未闭合标签、推理代码块，以及思考过程／最终回答分段。
  • 接口独立返回的 reasoning_content 不再被当成正文；只有思考、没有正文时会给出重试提示。
  • 旧聊天和剧情在显示时也会过滤明确的思考标记，保留角色正常内心描写与玩家输入。
  • 保留三组 API 独立分配、世界搭建校验、密码盘和此前全部更新。
