这次更新了什么

  • 短信会话设置的「关系」标签新增长期记忆：默认每 10 轮后台整理，支持调整轮数、手动整理、编辑和清空。
  • 一组玩家发言与其后的角色回复计一轮，角色连发多条不重复计数；摘要合并已有记忆并自动用于后续回复。
  • 每个身份与会话分别保存记忆，群聊保留发言人与经历归属；整理失败保留原记忆和进度。
  • 模型不可用错误提供中文说明和操作指引，可展开原始诊断。
  • 聊天中的系统提示支持单条删除与多选删除。
  • 保留防截断、冬日主题、七组 API 及此前功能。
