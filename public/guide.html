第一次打开

01 / START HERE

先走完这四步，剩下的可以边玩边发现。

STEP 01

先给自己一个身份

上滑解锁，到「设置 → 身份」填写称呼和人设。以后想换一种人生，可以新建另一个身份。

STEP 02

连接一个可用的模型

在「设置 → 连接 → 接口与模型」填写地址与密钥，拉取并选择模型，保存。七组 API 怎么分配？ 没有密钥时，先看免费领取教程。

STEP 03

认识第一个角色

去短信通讯录添加人物或导入角色卡。想从零捏一个人，试试「创作」；想做一群人，试试「世界搭建」。

STEP 04

发一句话，等一个回应

发出你的第一条短信，再点「让对方回复」。想找更多玩法，在市场安装喜欢的 APP，回桌面翻页找图标。

⌕

输入关键词，可同时筛选下方的小技巧和 APP 图鉴。

藏在日常里的小技巧

02 / LITTLE THINGS

有些功能，不必到设置里找。试着像和一个人说话那样，向 TA 提议。

01

换头像，不用退出聊天

在私聊点「＋ → 相册」发一张图片，再告诉 TA 想换成这张。发完点「让对方回复」；TA 同意并触发修改后，聊天里会出现换头像的系统提示。

可以这样说

这张给你，要不要换成头像？我觉得很像你。

发了好几张时，说清要用第几张；只有一张时用的就是这张。发图本身不会保证自动换上，角色也可以按人设拒绝。

02

昵称与签名，也可以聊着改

想换称呼或签名，可以直接在聊天里提议。TA 愿意修改时，资料会随回复更新，不用让玩家手写内部指令。

可以这样说

要不要把签名改成「今天也有好好生活」？

如果只是想给自己看的备注，去会话设置修改备注；备注与 TA 的昵称是不同的。

03

一句话拆成几条发

你可以先把一段话分几条发出去，补好情境，再点「让对方回复」。不用为了让 TA 回应，一直重复发送同一句。

可以这样说

我刚下班。
路过那家店的时候，突然想到你了。

回复太长或太碎，可在会话设置里调整「最少几条／最多几条」。

04

给相处留一点共同过往

会话设置里可以补充两人已经经历的事；常驻世界规则则放到世界书。让关系有具体来处，比只写「我们很熟」更好接话。

可以这样说

我们去年冬天一起去看过海，回程时约好明年还要再去。

只写你愿意确立的事实；刚开始的故事，也可以保留陌生和试探。

05

一起读，不必逐段转发

从聊天的「＋ → 一起听／读」进入，选好角色，导入正文并开启共享阅读。翻到哪一页，新的短信请求就提供哪一页。

可以这样说

这一页让我想起你上次说的话，你怎么看？

一起听需要歌名、歌词等信息；播放声音本身不会自动识别歌词。

06

约定，留给未来的某一天

聊天里提到具体的未来安排，可能形成待确认约定；也可以直接在共度里写内容、地点和现实时间。

可以这样说

这周六晚上七点，在河边那家面馆见，好不好？

到共度检查并确认安排。应用关闭或被系统挂起时，不保证自动提醒或主动消息继续运行。

07

回针里的权限是双向的

角色愿意给你看的应用，与右上角你允许角色看的内容，分别设置。觉得 TA 突然提起某个搜索或生活记录，先看看开放了什么。

这些是虚构手机内的内容，不会真的读取你系统里的短信、相册或其他 App。

08

换身份，像换一台小手机

在设置的身份分类里切换。人物、聊天和许多生活记录随身份分开；API 设置属于小手机的全局连接设置。

网页版与 APK、不同设备或浏览器不会自动同步本机记录；迁移前先导出备份。

没有找到相关小技巧，可以换个关键词，或看看下面的 APP。

APP 口袋图鉴

03 / THE APP INDEX

先看它能做什么，再展开「怎么用」。标着 AI 的功能会调用你配置的模型；普通记录、编辑和本地小游戏通常不用。

聊
相处 · 01

短信

AI 对话

聊聊天，也交换一点生活。

怎么用 · 小巧思＋
  1. 在通讯录添加人物、导入角色卡，或从附近的人认识新朋友。
  2. 打开私聊或群聊，输入并发送消息；发完可点输入栏旁的「让对方回复」。
  3. 点「＋」找相册、表情包、礼物、红包、转账、一起听／读；右上角可以通话、设置会话。

试着这样玩可以连发几条，再让 TA 一起回复。短信里的「发现」还藏着朋友圈、附近的人等入口。

伴
相处 · 02

共度

部分功能用 API

让相处留下后续。

怎么用 · 小巧思＋
  1. 先选「和谁共度」，每个人的共同生活分别记录。
  2. 从约定、日常、来访、人际、礼物、关系、相册几个分页开始玩。
  3. 约好具体时间、给 TA 的烦心事提建议、邀请做客，或给共同相册留一件小事。

试着这样玩聊天中提到的未来安排可能变成「待你确认」的约定；确认后才算约好，不必只在聊天里反复翻找。

见
相处 · 03

线下

AI 剧情

从隔着屏幕，到眼前这一幕。

怎么用 · 小巧思＋
  1. 建立线下存档，选好参与角色和场景。
  2. 用对白或动作推进当下的见面，例如「把刚买的热饮递给他」。
  3. 在详情里调整阅读、回复长度、总结和记忆；离开时保留存档。

试着这样玩线下会参考已有短信里的关系变化。想演一场见面，先在短信约好时间与地点，会更有接续感。

另
相处 · 04

番外

AI 剧情

给另一种可能，留一个存档。

怎么用 · 小巧思＋
  1. 新建番外，选择一位或多位参与人物。
  2. 设好这条故事的人设和开场，再开始演绎。
  3. 不同走向可分别存档；复制存档后继续尝试另一种选择。

试着这样玩适合「如果当年没有错过」或其他平行故事。多人番外可在详情中增减参与者。

窥
相处 · 05

回针

AI 内容

彼此愿意打开的那一小块屏幕。

怎么用 · 小巧思＋
  1. 选择并绑定角色，查看 TA 愿意开放的手机应用。
  2. 打开角色手机里的短信、浏览器、朋友圈等；需要时刷新内容。
  3. 右上角权限设置，是你允许 TA 看你的哪些内容。

试着这样玩「我能看 TA」和「TA 能看我」是两件事。权限可以自己调整，TA 对你开放多少也会结合相处情况判断。

城
相处 · 06

地图

部分功能用 API

把日常放进一座小城。

怎么用 · 小巧思＋
  1. 点地点查看与前往，用搜索、放大和缩小寻找地方。
  2. 可以自己添加地点，或让 AI 根据一句灵感设计新地点。
  3. 在地点留下见闻，和人物见面，继续眼前的小场景。

试着这样玩给常去的地点起具体名字，例如「河堤旁那家旧书店」。这里是虚构城市示意图，不是真实定位地图。

绘
世界 · 07

创作

AI 生成

把一个人物念头，做成角色卡。

怎么用 · 小巧思＋
  1. 写下想要的人物、性格、背景和关系方向。
  2. 按需要沿用已经启用的世界观，再生成角色。
  3. 检查并修改结果，确认后再添加到自己的小手机。

试着这样玩想要的是「一个人」就用创作；想做「一个世界里的一群人」，去世界搭建更顺手。

筑
世界 · 08

世界搭建

AI 整理

一段设定，拆成世界与人物。

怎么用 · 小巧思＋
  1. 直接写世界观，或导入世界文件；不必先把手写内容整理成 JSON。
  2. 等待拆分，查看世界设定与 NPC 名单。
  3. 确认导入后，人物成为可用角色，世界总设定写进世界书。

试着这样玩时代、地点、规则、人物之间的关系写得越清楚，越容易得到可玩的结果。大世界可分批整理。

书
世界 · 09

世界书

设定管理

把需要记住的设定，放到正确的位置。

怎么用 · 小巧思＋
  1. 在「世界观」与角色相关条目之间切换。
  2. 新增或导入条目，填写标题、关键词和具体内容，并启用需要的条目。
  3. 角色卡自带世界书时，也可查看并导入相关设定。

试着这样玩共用的城市规则放世界观，某人的秘密放角色条目。世界搭建导入的总设定在「世界观」里找。

笺
世界 · 10

旧世

AI 剧情

入幕演绎，也传一封短笺。

怎么用 · 小巧思＋
  1. 进入旧世小手机，先设好此世身份与经历。
  2. 导入古风人物；用「入幕」继续剧情，用「传书」来往书信。
  3. 需要补充时代规则时，打开旧世里的世界书或世界搭建。

试着这样玩旧世有自己的身份、剧情和世界书。古代人物与现代短信人物分开。长按底栏召唤低头，在「角色」页可以把随身卡装进当前身份：现代进短信，古风进旧世。装之前会先确认身份。

玩乐 · 11

星博

AI 社区

在人群里，看见熟悉的名字。

怎么用 · 小巧思＋
  1. 刷新看看新动态，点进详情阅读、点赞和评论。
  2. 也可以自己写一条动态。
  3. 用关键词搜索想看的相关话题与帖子。

试着这样玩这里是生成的虚构社区，不是真实社交平台搜索。可以试试一个小众兴趣，看看路人会聊出什么。

帖
玩乐 · 12

论坛

AI 社区

发一个话题，等故事长出来。

怎么用 · 小巧思＋
  1. 挑选板块看帖，打开帖子与回复。
  2. 自己发帖、评论，或者给一句想看的剧情方向。
  3. 输入关键词，生成一批相关话题继续逛。

试着这样玩同样一件小事，用求助帖、树洞帖或吃瓜帖的口气写，讨论气氛会很不一样。

局
玩乐 · 13

桌游

部分功能用 API

一起玩一局，比尬聊更容易开场。

怎么用 · 小巧思＋
  1. 选好参与人物，再选海龟汤、你说我猜、谁是卧底、谁是瞎掰王、狼人杀、UNO、五子棋或象棋。
  2. 跟着当前回合的操作提示行动；需要角色发言时等生成完成。
  3. 用桌边对话聊两句，结束后回看游玩历史。

试着这样玩角色会结合人设参与桌边互动。五子棋可切换放大棋盘和全盘；海龟汤要把问题提交给主持人，也可以换一题。谁是卧底只描述自己的词再投票；谁是瞎掰王各自编一个像真的答案，再投票哪条是标准答案。

风
玩乐 · 14

乘风

虚拟货币

玩一会儿，赚一点小手机里的零钱。

怎么用 · 小巧思＋
  1. 试试接花、配色、翻牌、数序、节拍等小游戏。
  2. 也可以选择工作时长，开始放置工作，完成后领取工资。
  3. 想换个玩法，还可以看看刮刮乐和彩票。

试着这样玩这里的金币是游戏内虚拟货币。工作按选择的时长结算，先接班，再回来收工。

玩乐 · 15

多淘

部分功能用 API

认真挑一份礼物，也可以买给自己。

怎么用 · 小巧思＋
  1. 看商品详情，将喜欢的东西加入购物车。
  2. 结账前选好收件人；不同店铺按界面分店结算。
  3. 下单后等配送，再看看收件人的反应和共度里的礼物记录。

试着这样玩可以写一句留言。送给谁、要不要提前告诉 TA，会让收到礼物时的情境不同。这里是小手机内的模拟购物。

闪送

部分功能用 API

想把一份吃的，送到 TA 手上。

怎么用 · 小巧思＋
  1. 挑吃的、加购物车，检查数量与金额。
  2. 选择送给自己或角色，再结账。
  3. 留意订单状态；送达后再接着聊这份心意。

试着这样玩结账不等于立刻送到。适合配合一句「别又忘记吃饭」，让吃饭这件小事有后续。

本地记录

今天的这一页，先留给自己。

怎么用 · 小巧思＋
  1. 选日期，写下当天的小事与心情。

试着这样玩角色不会因为你写了日记就自动知道内容；想让对方知道，可以主动聊起，或检查自己开放的手机权限。

怎么用 · 小巧思＋

写作助手

接住原来的语气，再往前写一点。

怎么用 · 小巧思＋

试着这样玩比起只有「帮我写一篇」，先放一段自己的文字，更容易保住人称、口气和故事正在发生的事。

音乐速记

本地记录

先记住一句词、一段旋律的念头。

怎么用 · 小巧思＋
  1. 写下旋律印象、歌词片段或灵感。

设
工具 · 25

设置

手机管理

先把自己的小手机安顿好。

怎么用 · 小巧思＋
  1. 「身份」里管理不同身份；「连接」里配置接口、模型和 MiniMax 语音。
  2. 「对话」里选预设、调整角色行为和通知；「外观」里调主题与图标。
  3. 「数据」里管理隐私锁、导出备份与恢复数据。

试着这样玩1.1.10 可保存最多七组 API，并按模块分配。改变默认接口，不会替换已明确绑定的模块。

工具 · 26

市场

应用管理

少一个图标，就来这里找。

怎么用 · 小巧思＋
  1. 按分类浏览，或直接搜索应用名称。

05 / CONNECTIONS

最多七组，每个模块只选一组。

短信长期记忆：打开会话右上角「… → 关系 → 长期记忆整理」。默认每 10 轮后台总结，角色连发只算一轮，可调整轮数、立即整理、编辑或清空记忆。整理使用短信模块的 API，会增加接口用量；失败不覆盖旧记忆，也不推进进度。系统提示右侧的垃圾桶可删除提示，多选删除也支持提示内容。

「回复完整性」中可设置防截断（默认开启）、输出额度和请求等待时间。推荐 8192 tokens、180 秒。若接口返回「请求参数校验失败」，会自动改用更兼容的参数并降低额度重试；短信按完整句子拆条，半句不会从中间切开；线下正文按行显示。仅有思考或正文截断时最多额外请求两次，可能增加耗时与 API 用量；补全失败会保留已有正文并提示。

入口是「设置 → 连接 → 接口与模型」。一组 API 保存自己的地址、密钥与模型；同一组可以供多个模块使用。

  1. 新建 API，填写信息，拉取并选择模型后保存。
  2. 选一组作为默认接口，供未单独分配的模块使用。
  3. 下滑到「应用模块分配」，为短信、线下、世界搭建等分别选择。
API ① → 短信、共度API ② → 线下、番外、旧世API ③ → 创作、世界搭建

上面只是分配示例。给同一模块换一组，会替换原绑定，不会同时调用两组。绑定自动保存；删除 API 会清理相关绑定。MiniMax 语音在单独的语音页面设置。

为什么聊了几轮，免费额度就用完了？

对话轮数不等于 API 请求次数。主动消息、长期记忆整理、总结和防截断补全都可能额外请求接口；部分平台失败请求也占次数。额度较少时，可调大记忆整理轮数，减少主动消息和并发后台任务；不要连续点击重试。

401、402、403、429 和模型不可用分别怎么办？

401：检查 Key 是否复制完整且属于当前地址。402：查看平台余额或当前模型的付费要求，重新确认免费型号。403：核对地区、账号、项目权限与平台要求。429：通常是速率或配额限制，按控制台提示等待或减少用量。model_not_found / 模型不可用：重新拉取模型，选仍在服务且账号可用的型号。重新创建多个 Key 不会自动增加账号配额。

浏览器“Failed to fetch”，但官方控制台能聊天？

官方网页可用不等于允许半糖网页跨域直连。先核对地址、网络和平台是否允许第三方客户端调用；不要把 API Key 放进不认识的公共转发地址。需要代理时，只使用你自己信任并已了解数据流向的服务。

这些地址也能直接用于 MiniMax 语音吗？

本节讲的是文本聊天 API。MiniMax 语音使用独立的语音配置，免费聊天额度不会自动变成语音服务额度。

遇到问题时

07 / A LITTLE HELP
发了图片，头像怎么还没换？

在角色私聊里发图，再明确提议换头像，点「让对方回复」。它不是发图后的固定自动动作：角色愿意并触发修改时，才会换成你指明的那张。发了好几张却没说用哪张，就不会猜着换。成功后会有系统提示；只有口头答应而没有提示，也可能是模型这次没触发修改。

角色不回复，先查哪里？

先点「让对方回复」，看有没有错误提示。到设置检查该模块实际绑定的 API：地址、密钥、模型和额度是否可用。若开启了主动聊天，还要检查该角色是否允许主动消息，以及页面是否仍在运行。

为什么没有某个 APP？

先去市场搜索并安装，再回桌面翻页找。朋友圈、附近的人等入口在短信的发现区域；一起听读既可从短信「＋」进入，也可到外部连接打开。

TA 为什么知道我搜过什么？

到回针检查你对这个角色开放的手机权限。搜索等已授权的小手机内记录可能进入聊天上下文；没有授权的内容，不该凭空当成 TA 已经看见。关闭权限会影响之后的新请求，不会撤回已经发出的消息。

保存了日记，角色就会看到吗？

不会因为保存日记就自动广播给角色。你可以自己提起，或按需要管理回针里的可见范围。写作记录、阅读共享与实际短信也各有自己的入口，别把「保存」当成「发送」。

一起听没有歌词，或一起读没反应？

先选陪伴角色，打开对应共享开关。歌词需要保存到当前歌曲；只有音频不会自动得到歌词。阅读要先导入正文，普通网页链接不等于正文。可试「让 TA 聊聊当前内容」，根据提示检查。网易云登录说明 ↗

世界搭建失败，怎么办？

保留原始资料，看看界面显示的原因。较大的世界可以缩小本次人物范围、分批整理；检查「世界搭建」模块绑定的接口是否能返回完整内容。1.1.7 会校验 JSON 并在格式异常时重试一次，仍不合格时会给出错误提示。

通话一定能听到声音吗？

通话可以先用文字进行。需要实际播放语音时，到「设置 → 连接 → MiniMax 语音」配置语音服务，并检查角色音色与语音开关。通话界面中的打字对话，不等于已经开启麦克风实时语音识别。

能把网页版的聊天自动带到 APK 或另一台手机吗？

不会自动同步。本机数据随浏览器、应用与设备环境保存。迁移前在「设置 → 数据 → 备份与恢复」导出备份，再到目标环境恢复；更新 APK 时沿用官方同签名安装包覆盖安装，不要先卸载或清除数据。

网页关掉后，TA 还会一直主动发消息吗？

自动陪伴、定时检查等依赖页面或应用正常运行。关闭网页、系统挂起、后台节电时，不保证继续执行。想减少打扰，可到通知设置或对应聊天关闭主动消息。
