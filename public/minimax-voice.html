MiniMax 语音接入

在半糖 Mellow 里让角色语音条开口说话。按下面步骤配置后，通常能拉到三百多个系统音色。

1. 准备密钥

  1. 打开 MiniMax 开放平台 · 接口密钥，登录后创建或复制 API Key。
  2. 在同一页的账户信息里找到 GroupId（一串数字）。半糖会把它附在语音合成请求上。
  3. 密钥是一长串 JWT，以 eyJ 开头。只填在本地设置里，不会上传。

2. 在半糖里填写

设置连接MiniMax 语音

  1. 语音接口填 https://api.minimax.cn
  2. GroupId 填你的数字 GroupId
  3. 语音密钥 粘贴 API Key
  4. 语音模型选 speech-02-hd 或更新的 speech-2.8-hd

3. 拉取与试听

  1. 点 拉取音色。成功后会显示「拉到 300+ 个音色」一类提示。
  2. 在「默认角色音色 / 我的音色」下拉里选一个，可用上方搜索框过滤。
  3. 点 试听默认音色，确认能听到声音。
  4. 最后点 保存语音。短信里点语音条才会调用 MiniMax。
若拉取失败：检查密钥是否过期、GroupId 是否填对、网络能否访问 api.minimax.cn。拉音色只需要密钥，不需要 GroupId。

4. 常见问题

  1. 只有 30 个音色？ 说明还没拉取成功，仍在用内置旧名单。请重新点「拉取音色」。
  2. 试听没声音？ 先保存语音，并确认浏览器没有静音；合成接口需要 GroupId。
  3. 角色语音条没反应？ 会话里也要开启 MiniMax，且该条消息是角色发的文字。
