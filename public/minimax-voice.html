MiniMax 语音接入教程

三步搞定，轻松拥有专属 AI 音色

1

第一步：获取国内账号信息

建议用电脑操作，或者用手机浏览器（如 QQ 浏览器）切换到「桌面模式」，手机页面可能显示不完整。

1. 注册并登录账号

访问国内平台：https://platform.minimaxi.com

使用手机号 + 验证码登录即可。

2. 获取 API Key（接口密钥）

  1. 登录后，点击页面右上角的头像 → 选择「账户管理」→ 找到「接口密钥」
  2. 点击创建新密钥，然后复制并保存好你的 API Key，这是调用语音功能的重要凭证

如图所示：创建并复制 API Key

3. 获取 Group ID（团队 ID）

  1. 在「账户管理」的「基本信息」里，找到「团队 ID」（Group ID）
  2. 复制并保存 Group ID，注意不是用户 ID

如图所示：复制团队 ID（Group ID）

4. 完成实名认证（强烈推荐）

实名认证后通常会赠送 15 元代金券，可以使用很久。

需要保存的信息：

  • API Key（接口密钥）
  • Group ID（团队 ID）

这两个信息稍后会用到，请妥善保存。

2

第二步：制作专属音色

重要说明：国外平台克隆音色第一次调用不会扣费 9.99 美元，所以我们要去国外平台制作音色 ID，然后配合国内的 API 使用。

1. 打开国外平台并登录

访问：https://www.minimax.io 或 https://www.hailuo.ai/audio

使用同一个账号登录（和国内平台账号通用）。

2. 进入音色克隆页面

点击左上角的三条杠菜单 → 选择「Voice Clone」（音色克隆）。

3. 上传音频样本

准备一段清晰的音频文件：

  • 时长：10～300 秒（建议 15～30 秒）
  • 格式：MP3
  • 大小：尽量控制在 KB 级别，太大的话可以先用小程序压缩
  • 质量：越清晰越好，背景噪音越少越好

点击上传并等待处理。

4. 设置音色信息

  • 选择音频的主要语言（中文 / 英文 / 日语等）
  • 勾选同意协议
  • 点击「Convert」或「复刻」按钮开始训练

重新生成不消耗机会，只有确定后才会消耗配额。

5. 获取 Voice ID（音色 ID）

  1. 音色克隆成功后，给它取一个名字（方便自己记忆）
  2. 复制显示的 Voice ID（格式通常是 male-xxxx 或 female-xxxx）
隐私提醒：你生成的音色 ID 可以被其他人通过搜索名字找到并使用。如果介意的话，请给音色取一个随机复杂的名字，并自己记好。如果忘记了 Voice ID，可以在音色列表中搜索你取的名字找回。

音色命名规则：

  • 必须以英文字母开头
  • 不能包含特殊符号
  • 不能与他人重复（如果重复，可以在后面加数字）
3

第三步：在半糖 Mellow 中配置

1. 打开半糖 Mellow

进入 设置 → 连接 → MiniMax 语音。

2. 填入 API 信息

将第一步保存的两个信息填入对应位置：

  • 语音接口：https://api.minimax.cn
  • GroupId：你的团队 ID
  • 语音密钥：你的 API Key（以 eyJ 开头）

3. 填入音色 ID

将第二步复制的 Voice ID（如 male-xxxx）填入「默认角色音色」；若下拉里没有，可先点「拉取音色」刷新列表，或在聊天设置里为单个角色指定音色。

「我的音色」用于你自己发出的语音条，可按需填写。

4. 选择语音模型（可选）

推荐 speech-02-hd 或更新的 speech-2.8-hd，按平台可用情况选择即可。

5. 拉取、试听并保存

  1. 点「拉取音色」，确认连接正常
  2. 点「试听默认音色」，确认能听到声音
  3. 点「保存语音」，回到短信即可使用语音条

如图所示：在半糖 Mellow 中填入配置信息

常见问题

为什么要在国外平台制作音色？

因为国外平台克隆的音色 ID 第一次调用不会扣除 9.99 美元，可以节省费用。克隆好音色 ID 后，配合国内的 API 使用即可。

音色 ID 会过期吗？

不会过期。一旦创建成功，就可以一直使用。

可以创建多个音色吗？

可以。你可以创建多个不同的音色 ID，分别用于不同的场景或角色。

如果音色效果不好怎么办？

建议重新上传更清晰、时长更合适的音频样本。音频质量越高，克隆效果越好。

API Key 和 Group ID 可以共享吗？

不建议共享。这些是你的账号凭证，关系到费用扣除和使用记录，请妥善保管。

15 元代金券可以用多久？

根据实际使用量而定。MiniMax 的语音合成按字数计费，正常使用的话 15 元可以用挺久。

为什么我的配置无法连接？

请检查：API Key 和 Group ID 是否填写正确（注意不要有多余空格）；是否完成了实名认证；账户余额是否充足；Voice ID 格式是否正确。

快速回顾

三步搞定：

  1. 在国内平台获取 API Key 和 Group ID
  2. 在国外平台制作音色并获取 Voice ID
  3. 在半糖 Mellow 中填入这三个信息

完成配置后，你就可以在半糖 Mellow 中使用你的专属 AI 音色啦。如果遇到问题，可以重新检查每一步的配置是否正确。
