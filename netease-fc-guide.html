打开网页版扫码登录教程

下方部署步骤保留作维护参考。

下载备用 FC 代码包 ZIP

先确认函数计算服务

在手机浏览器打开 阿里云函数计算控制台 ↗，用自己的阿里云账号登录。

函数计算会按使用量计费，不保证免费。首次开通是否有试用额度，以你的控制台为准。先查看开通协议与费用说明，再决定是否使用。这里还没有替你开通或创建任何阿里云资源。

不用购买整台服务器。如果看到开通页面，或找不到下方的配置项，可以先回到聊天说明当前页面，再继续。

创建并上传

  1. 地域可先选华东 1（杭州），进入「函数管理 → 函数列表 → 创建函数」，选择事件函数。
  2. 函数名称填 mellow-netease-account，运行环境选 Node.js 20。采用 CPU 规格，内存可先设 256 MiB，其他资源规格按控制台可用的较小档位设置。
  3. 通过「上传 ZIP 包」上传刚下载的文件，并确认保存 / 部署。代码根目录应直接包含 index.mjs、netease.mjs 和 LICENSE.txt。
  4. 处理程序填 index.handler，超时时间可设 60 秒。保留公网出站访问权限，以便请求网易云。
  5. 若可设置弹性实例策略，最小实例数设 0，先限制最大实例数为 1。在阿里云费用中心设置预算提醒；这些配置不是费用硬上限。

手机页面显示不全时，可启用浏览器的“桌面版网站”。不需要安装依赖或把阿里云密钥填进网页。

创建 HTTP 入口

  1. 进入该函数的触发器设置，添加 HTTP 触发器。
  2. 为网页访问使用无需认证 / anonymous的触发器入口。账号会话由代码自身检查；请勿启用要求阿里云 AccessKey 签名的入口。
  3. 允许方法选 POST、OPTIONS、GET。保留代码自己的 CORS 响应；不要额外设置冲突的跨域规则。
  4. 复制控制台生成的HTTPS 公网访问地址，发回聊天。只发这个公开地址，不发 AccessKey、密码、网易云 Cookie。

先测试默认触发器地址，不用立刻重新修改刚才那三条 DNS，也不用先绑定自定义域名或配置自定义证书。

拿到地址后我继续做

我会检查线上来源许可、有效二维码生成与扫码状态，再切换半糖网页的登录线路。之后你关闭 VPN，从 HTTPS 半糖网页扫码确认，并验证账号和歌单读取。全流程通过前，不会报告“免 VPN 已修好”。

如果旧数据在 HTTP 半糖中，切换 HTTPS 前先从设置导出备份，进入 HTTPS 版后导入；两种地址的数据存储独立。
