# 网易云账号连接教程（半糖 1.0.4）

## 登录与歌单

1. 覆盖安装半糖 1.0.4 APK，不要先卸载旧版。进入「外部连接」。
2. 找到「网易云账号 · 我的歌单」，点「连接网易云账号」。这个入口已内置云服务，不需要填写 MCP URL、令牌或密码。
3. 截图保存生成的二维码，切换到网易云 App，打开「扫一扫」，从相册识别二维码。
4. 在网易云 App 中亲自确认登录，然后返回半糖。通常会自动完成；也可点「我已确认，检查登录」。
5. 登录成功后，会显示账号昵称及你创建、收藏的歌单。歌单超过 30 个可点「加载更多歌单」。
6. 打开一个歌单，点歌曲右侧的「播放」。较长的歌单可翻页查看。

此连接使用网易云网页接口适配，并非官方 OAuth 集成。实际登录及私人歌单访问需用你自己的账号验收；平台可能要求重新登录或限制第三方请求。

## 让 char 自动陪你听

1. 在同一页上方「陪伴 · 一起听，一起读」选择 char。
2. 开启「共享音乐」。
3. 希望 TA 自己发消息，就开启「主动聊天」，选择聊天间隔。
4. 从网易云歌单选歌播放时，播放器会获取该账号可用的音频及歌词，当前歌曲和附近歌词自动提供给所选 char。
5. TA 的主动回应会出现在短信里，无需每首歌另发消息。立即试用可点「让 TA 聊聊当前内容」。

此功能需要你原先已配置可用的聊天 API。音乐账号连接与聊天 API 是两套独立设置；音乐账号凭据不进入角色提示词。

## 登录保存与断开

- 登录凭据加密保存在这台手机、当前身份的本地存储中，不进入小手机导出备份或歌单数据。
- 云端每次处理账号查询时会使用登录凭据，不设全站共用账号，不把一个人的账号交给其他用户。
- 换设备、导入备份、清除应用数据或登录过期后，需要重新扫码。
- 点「断开账号」会移除半糖本机连接，并暂停正在播放的网易云歌曲。如需在网易云端撤销登录会话，请在网易云账号安全设置中管理。

## 限制与排查

- **HTTP 网页不能登录账号。**请使用 APK 或安全的 HTTPS 页面；HTTP 网页仍能使用公开搜歌和 TXT 共读。
- 二维码通常两分钟内有效。提示过期后，点「刷新登录二维码」。二维码由手机本地生成，不使用第三方二维码图片服务。
- 扫码后还要在网易云 App 中确认。回到半糖仍显示等待时，可点「检查登录」。
- 显示「登录已失效」时，重新扫码即可。
- 歌曲能否播放取决于账号权限及平台实际返回的音频；只提供试听时，会提示试听片段。没有可用音频时会明确报错，不绕过会员、地区或平台限制。
- 这会同步**半糖内部播放器**的歌曲与进度，不会监视网易云 App 自己正在播放什么。
- 锁屏、系统挂起或关闭页面时，自动聊天和播放不保证继续。真实私人歌单、音频和手机上的扫码流程仍需你本人登录测试。
