# 半糖 Mellow：和 char 一起听歌、读小说

所有日常设置都在小手机里完成，无需配置 Codex 的 MCP。先在小手机「设置」里配置可用的聊天 API，并在通讯录添加 char。

## 入口与基本设置

在「市场」安装并打开「外部连接」，顶部就是「陪伴 · 一起听，一起读」。也可以从短信聊天的加号工具「一起听 / 读」进入；私聊进入会自动选中这个 char。

1. 选择陪伴角色。
2. 按需打开「共享音乐」或「共享阅读」。未开启的内容不会加入新的聊天请求。
3. 希望 TA 自己说话，就打开「主动聊天」，选择 1 / 3 / 5 / 10 分钟的最短间隔。
4. 主动回应会出现在该 char 的短信中，无需你先发消息。想立即试一次，点「让 TA 聊聊当前内容」。

只有内容变化且间隔已到时才会再次主动说；同一页不会不断重复点评。主动聊天使用已配置的模型 API，会消耗相应额度。如果该角色在聊天设置中关闭了主动消息，需要先开启。

## 一起听歌：不需要 MCP 的方式

1. 展开「一起听歌与歌词」，点小播放器左上角的设置按钮，导入本地音频或音频直链。也可以使用首页播放器已有歌单。
2. 在「陪伴播放歌曲」选择歌曲，点唱片开始播放。
3. 在当前歌曲歌词框粘贴歌词，或点「导入歌词」选取 `.lrc` / `.txt` 文件。
4. 点「保存这首歌词」。每首歌只需保存一次，以后切到这首歌会自动读取。
5. 打开「共享音乐」，保持歌曲播放。回到短信聊天，char 就会获得当前歌名、歌手和歌词；开启主动聊天后，TA 还会主动聊起来。

LRC 示例（时间为分:秒）：

```text
[00:05.00]这里是第一句歌词
[00:12.50]这里是第二句歌词
```

LRC 会根据播放进度选择当前附近的几句；纯文本歌词会提供前 1800 字，无法逐句对齐。播放音频本身不会自动识别或搜索歌词。没有歌词时，char 只知道歌曲信息，不应编造歌词。

播放器在小手机内部切换到短信或其他应用时可以继续播放。暂停播放后，新的聊天请求不再包含当前播放内容；已经发出的短信不会被删除。

## 一起读小说、文章或字幕

1. 展开「一起读小说 / 文章 / 字幕」。
2. 点「导入 TXT / 字幕文件」选择 `.txt`、`.srt` 或 `.vtt`；也可以填写书名，一次粘贴正文后点「导入文字」。
3. 正文会按约 1200 字一页显示。用「上一页 / 下一页」或页码输入框跳转。
4. 打开「共享阅读」。char 的新聊天请求会自动包含当前页；翻页后自动更新，不必逐段发送。
5. 打开「主动聊天」后，char 会根据当前页适时发短信。阅读内容只提供当前页，不把后面章节一起发给模型。

建议导入 UTF-8 文本；单文件小于 6MB，正文不超过 200 万字。长篇可以按卷导入。字幕以文字分页阅读，不会自动识别电影画面或跟随视频时间。

也可在「正文直链」填写允许跨域访问的 TXT 地址，然后点「读取正文直链」。普通小说网站的章节页面、登录页面和分享页面通常不是 TXT 直链；读取失败时，用文件导入或下面的 MCP 方式。

## 外部音乐 / 网页：使用 MCP 自动读取

这是可选进阶功能。你需要有一个真实可用的 MCP 服务，它能访问你的音乐状态、歌词或小说正文。小手机不会仅凭网易云首页、小说网址或其他 App 名称就读取内容，也没有预置可用的个人账号连接。

1. 在同一页下方的「连接 MCP 服务」填写服务地址与可选的 Bearer Token。
2. 点「连接并发现工具」。
3. 选择服务提供的**只读查询工具**，查看参数格式并填写「工具参数 JSON」。
4. 先点「执行工具」，确认能返回真实歌曲或正文。
5. 在「自动读取给 char」选择「当前歌曲与歌词」或「小说 / 网页正文 / 字幕」。
6. 点「将当前工具设为自动读取源」。
7. 回到顶部选择 char；如果想让 TA 主动说话，再打开「主动聊天」。

绑定后，页面可运行且相应共享开关开启时，约每 30 秒查询一次；模型主动发言另受聊天间隔限制。一次只绑定一个自动读取工具；更换绑定会替换旧工具。工具需要自行决定“当前歌曲 / 当前章节”，小手机不会自动登录平台或翻动外部网站。

音乐工具返回值可以放在 MCP 的 `structuredContent`，也可以作为文本 JSON 返回：

```json
{
  "name": "歌名",
  "artist": "歌手",
  "lyrics": "[00:05.00]一行歌词",
  "position": 12,
  "playing": true
}
```

`position` 为秒；`playing: false` 表示暂停共享当前播放内容。也支持将这些字段放在 `nowPlaying` 对象里。若没有 `position`，按 0 秒处理；纯文本歌词不需要时间。

小说、文章或字幕查询工具返回：

```json
{
  "title": "书名 · 第三章",
  "text": "当前章节或当前页面的正文"
}
```

也支持放在 `reading` 对象里，或直接返回正文文本。返回内容更新时会回到新内容第一页；相同内容再次同步会保留当前阅读页。

服务必须支持 Streamable HTTP，并允许小手机站点跨域访问与读取 `Mcp-Session-Id` 响应头。本地 STDIO、OAuth 登录界面没有在这个入口实现。令牌与连接仅驻留本次页面内存；页面刷新后需要重新连接和绑定。

歌单导入仍可使用原有「导入返回歌单到播放器」按钮，歌曲数组支持 `name`、`src`、`artist`，现在也支持 `lyrics`，导入时一起保存到歌曲。

## 如何停止与排查

- 点「结束陪伴」：关闭音乐共享、阅读共享与主动聊天，同时解除 MCP 自动读取。
- 仅停止外部查询：点「停止 MCP 自动读取」。已经导入的正文仍在阅读面板；如不想继续共享，再关闭「共享阅读」。
- TA 不说话：检查聊天 API、所选角色、共享开关、当前是否播放 / 有正文，以及角色的主动消息设置。试点「让 TA 聊聊当前内容」，查看面板状态提示。
- 读不到歌词：保存歌词到正确歌曲，或检查 MCP 服务是否返回 `lyrics`。
- 看不到未打开章节：这是正常的，模型只收到当前页，不会自动获得整本书后文。
- MCP 失败：检查地址、令牌、工具参数、服务跨域配置，面板会显示错误原因。

自动同步与主动聊天依赖页面运行；在网页关闭、手机系统锁屏挂起或后台节电时，不保证继续运行。切换到「线下 / 旧世」沉浸模式时，会暂停自动短信陪伴。共享资料只加入所选角色的短信请求，其他角色不会获得；关闭共享不会撤回已进入聊天历史的消息。

## 本次验证范围

通过 TypeScript 与生产构建，以及使用模型替身的完整短信链路回归：歌词时间匹配、当前页限制、角色与身份隔离、并发与冷却、停止共享、MCP 定时读取与错误提示。真实外部音乐 / 小说服务及真实模型需要使用你自己的服务连接测试；本轮浏览器自动化环境启动失败，未完成真实点击和音频播放验收。
