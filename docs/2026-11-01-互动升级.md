# 2026-11-01 互动与生活升级

- 桌游：桌边对话接入当前角色人设和亲密度；棋局/UNO动作触发角色反应。亲密且不争强的角色可能在五子棋与UNO选择较弱策略。你说我猜使用玩家实际提示，轮换词卡；狼人杀支持发言、逐人回应、依据公开发言投票、出局观战；海龟汤问题提交后显示主持人判断状态，模型回答立即写回界面；失败显示重试原因。
- 五子棋：15×15，共225个落点，支持切换放大棋盘与全盘。
- 回针：角色手机主屏幕、SVG应用图标、短信会话气泡、真实对话表情包图片。进入应用才请求生成，没有固定短信/相册/日记填充；失败显示重试提示。旧预设窥屏记录不会迁入新生成数据。
- 外部连接：分区保留、收藏表单折叠、卡片和窄屏排版。连接网易云后可按歌名/歌手搜索、分页并播放。
- 网页图标：使用APK现有192px图标，补充iOS触摸图标与PWA图标。
- 乘风：1～1440分钟自选工作，工资经验按时长缩放，接班时锁定等级工资。
- 星博/论坛：搜索按钮按关键词现场生成一批相关虚构社区帖子；时间、季节、节日依据调用时设备现实时间。
- 兑换：本机账号范围解锁一次，旧领取记录自动迁移。各身份分别直接领取，不需重新输入兑换码；兑换期结束后已解锁礼物仍可领。账号解锁随整机备份导出。
- 消息横幅：提高全局层级，查看别的应用时不因残留会话状态抑制；沿用勿扰、静音与通知设置。
- 地图：角色场景读取已有短信，共同经历写入角色专属记忆用于后续短信；未参与的角色无法读取。购买的住房显示在地图。
- 多淘/闪送：按商家进店，同店商品一起结算，其他店购物车保留；扣款、订单与购物车在同一事务写入。闪送改为20～40分钟模拟送达。
- 生活：两款购物应用的「生活」页提供食材采购、库存、三种配方做饭、三套住房、家具购买和分房布置，所有操作使用虚拟货币并持久保存。

## 网易云服务更新

网页使用阿里云账号服务。搜索新增 `search` 操作，需一并更新服务端。运行 `node scripts/build-netease-fc.mjs` 生成 `artifacts/netease-fc-package/`，将其中3个文件打包到ZIP根目录上传至原FC函数。Android直连搜索由前端共享协议处理，APK需重新构建。
搜索协议参考现有适配器上游：[cloudsearch模块](https://github.com/neteasecloudmusicapienhanced/api-enhanced/blob/master/module/cloudsearch.js)。尚未用真实账号验证搜索与版权音频，也没有在本轮部署远程服务。


## 共度：七项生活联动

新增固定应用「共度」，也能从短信的「＋ → 共同生活」和购物应用的生活页进入。按当前身份和角色分别保存：

1. **约定**：手动保存现实日期、地点与备注，聊天中明确谈到的约定由后台提为待确认草稿。支持确认、改期、取消、完成及记录未赴约。临近和错过时分别提醒一次，不自动判定玩家失约。完成后留下纪念。
2. **日常事件**：根据人设与既有聊天现场生成，保留事件阶段和玩家建议。开启「让TA的日常继续发生」后按现实时间推进，失败时重试同一阶段，主动短信仍遵循原有主动聊天、静音与勿扰设置。
3. **来家里**：做饭、看电影、聊天、留宿邀请都由角色按性格、关系与意愿接受或拒绝。家里一次只进行一场来访。对白会读取家具布置和以前来访；一起下厨真实扣除食材，饭菜、来访记录和纪念在同一事务保存。
4. **社交圈**：现场创建长期联系人，保持姓名、关系与生活线索，支持请角色介绍。回针短信优先沿用这些人，第一次在回针生成的联系人也进入社交圈。
5. **礼物**：聊天礼物和送达包裹保存为角色拥有的物品，可询问使用、收藏近况。角色能依据玩家喜好制定回礼计划，每个现实日积攒12枚角色自己的虚构预算（单次离线补算最多7天），不扣玩家余额；准备好后按主动短信设置送出，保留共同记录。聊天送礼的扣款、卡片、物品和纪念同一事务提交，重复请求不重复收费。
6. **关系**：熟悉、信任、心动、依赖独立变化，每轮最多变化3点。沿用已有信任与亲密基础，再依据实际聊天更新；不把高好感等同于无条件答应。地图、短信、来访与桌游都能读取相关背景。
7. **共同相册**：自动记录赴约、一起做的饭、礼物、来访与桌游结局；支持玩家自己上传照片和写纪念。模型只收到照片的文字说明，不把照片Base64塞进文本提示。开启日常后，角色可以适度提起真实纪念，不编造照片细节。

提醒和主动更新由打开的小手机页面运行；网页关闭时不会发系统推送，回来后根据真实时间检查。AI生成功能需要原有接口配置。全部新数据随整机备份导出，删除角色时一并清理。

验证：`npm run check:shared-life`，覆盖约定证据与确认、并发提醒去重、事件失败重试、来访拒绝、原子扣料、送礼原子扣款与回礼、隐私隔离、备份与角色删除。另完成390px手机宽度的浏览器检查：保存约定、聊天入口、无接口时错误反馈，无横向页面溢出。
