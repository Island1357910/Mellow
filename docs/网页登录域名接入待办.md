当前尚未验证“手机关闭 VPN 后可扫码登录”。此文件记录已准备的配置，不是完成报告。

## 登录接口域名

已在现有账号后端登记 `music-api.mymellow.top`，当前 pending，证书 initializing。域名管理者需添加以下记录（不会修改现有主站记录）：

```text
类型：CNAME
主机记录：music-api
记录值：custom-domains.chatgpt.site.

类型：TXT
主机记录：_openai-site-verification.music-api
记录值：openai-site-verification=5EAWQsszJKj0pIj5JoNDdR5s-Y-SNSljwTHRSXEYZf0

类型：TXT
主机记录：_cf-custom-hostname.music-api
记录值：20983008-632c-40a6-9f19-34c3f9b4fb23
```

部分 DNS 控制台使用完整主机名，此时分别填 `music-api.mymellow.top`、`_openai-site-verification.music-api.mymellow.top` 和 `_cf-custom-hostname.music-api.mymellow.top`，避免重复拼接域名。

这仍是现有 Cloudflare/Sites 后端的自有域名接入，并未迁移为国内服务器。更换域名是否足以解决用户网络的问题，必须实际测试；如仍不可达，需要改用用户可访问的云服务器或云函数，不能仅凭域名生效宣称免 VPN 已完成。

## 主站 HTTPS

GitHub Pages 诊断确认域名解析有效、支持申请 HTTPS，但尚无证书。开启强制 HTTPS 返回 `The certificate does not exist yet`；已重新提交相同自定义域名以重查，域名未变化。需等待签发或排查 DNS/证书配置后，再开启强制 HTTPS。不要跳过证书校验或在 HTTP 下保存账号凭据。

## 域名生效之后

1. 通过 Sites 刷新自定义域名验证，确认域名及证书均 active。
2. 测试新域名 `/api/account` 的 CORS 预检、qr_start 和 qr_check；在用户手机关闭 VPN 的网络上验证二维码生成。
3. 前端构建设置 `VITE_NETEASE_ACCOUNT_API=https://music-api.mymellow.top/api/account`。在域名验证成功前不要设置或发布这个地址。
4. 前端已支持这个构建变量，变更后端地址会使用独立的本地账号存储，避免自动把旧会话转给新接口。
5. 主站使用有效 HTTPS 后，用户本人在网易云扫码确认，随后验证账号信息和歌单读取。全流程通过后才能报告完成。

不需要用户手工填写 MCP 服务地址、令牌或网易云 Cookie。
